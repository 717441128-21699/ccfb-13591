# 基桩低应变反射波法完整性分析系统

面向工地批量基桩低应变检测的 Web 分析系统。导入每根桩的锤击加速度波形与设计资料，
自动完成速度积分、指数放大、桩底反射识别与波速反演、缺陷反射判读、多锤一致性剔除，
按 JGJ 106 给出 I~IV 类完整性判定，并在平面图上用颜色标注、对疑问桩并排展示波形与判读理由。

## 技术栈

- TypeScript + Vite，零运行时第三方依赖
- 核心算法为纯 TS，同一份代码在浏览器 Web Worker 与 Node 验证脚本中复用
- Web Worker 线程池按 CPU 核数并行，不支持 Worker 时自动降级主线程

## 物理与算法

### 波形合成（一维波动方程）
`src/core/synthesis.ts` 用特征线差分格点（CFL=1）求解弹性杆一维波动方程，
按阻抗变化界面自然产生反射：

- 缩颈/夹泥/断桩 → 波阻抗减小 → 速度反射与入射**同相**
- 扩径 → 波阻抗增大 → 速度反射**反相**
- 摩擦桩桩底近自由端 → 强同相反射；嵌岩桩底 → 弱/反相反射
- 阻抗突变边界做线性渐变过渡保证数值稳定；断桩用窄过渡保留强反射
- 可叠加桩头浮浆高频振荡（加速度域）、双击、测量噪声与零漂

### 分析链路（`src/core/analyzer.ts`、`consistency.ts`）
1. 加速度梯形积分 → 最小二乘去趋势 + 安静段去直流
2. 低通平滑、入射峰识别（限定记录前部，防强反射干扰）
3. 桩头浮浆识别：加速度域 2~3.5kHz 窄带谱（频带能量占比 + 谱峰比）
4. 指数放大补偿土中阻尼
5. 桩底反射：期望走时窗口内按极性/显著性/走时接近度/二次反射周期综合评分
6. 波速反演 c = 2L/Δt；缺陷扫描按相位、反射系数、周期反射区分缩颈/扩径/夹泥/断桩
7. 谐波抑制：周期回波归并到首道反射，避免把回波误判为新缺陷
8. 多锤对齐（±6 样本滞后搜索）相关分析，双击/低相关锤剔除
9. 跨锤事件聚类投票融合，强断桩锤受保护不被一致性剔除
10. JGJ 106 分类；强同相反射（|β|≥0.6）锁定 IV 类

### 关键安全设计
- **IV 类零漏判优先**：任一有效锤出现强断桩反射即锁定 IV 类，不被融合/投票稀释
- 断桩锤因波形独特导致相关系数低时，豁免一致性剔除
- 有效锤不足时兜底保留强断桩锤，报告标记疑问要求复测
- 疑问桩（低桩底置信、低复现、坏锤过半）自动标记转人工复核

## 目录结构

```
src/core/       物理合成、DSP、分析算法、数据导入（与环境无关的纯逻辑）
src/worker/     Web Worker 与线程池
src/ui/         Canvas 波形绘制、平面图、样式
src/main.ts     界面装配
test/           Node 验证、性能基准、导入测试
```


## 验证与基准

```bash
npm test           # 300 桩验收：深度误差、IV 召回、波速误差、耗时
npm run bench      # 单线程吞吐基准
node test/importCheck.ts   # 数据导入通路
SEED=111 npm test  # 换随机种子做稳健性验证
```

近期一次默认种子结果：

| 指标 | 结果 | 要求 |
| --- | --- | --- |
| IV 类召回 | 100%（52/52，5 个种子累计 278 根零漏判） | 不许漏判 |
| 波速反演误差 p95 | ≈4.4% | — |
| 深度误差 p50 | ≈2.9%（单缺陷 ≈2.1%） | — |
| 300 桩分析耗时 | ≈150ms 单线程 / 浏览器多 Worker 更快 | < 60s |

深度 p95 尾部误差集中在双缺陷复合桩与检测极限处的弱反射（反射系数接近噪声底），
这类桩自动进入「疑问」流程由检测员复核，符合现场质量管理制度。

## 实测数据导入

点击「导入实测波形」，支持 JSON 与 CSV（格式见「下载导入模板」）：

```json
{
  "piles": [
    {
      "meta": {
        "id": "S-001", "x": 0, "y": 0,
        "designLength": 18, "diameter": 0.8,
        "concreteGrade": "C30", "toeCondition": "friction"
      },
      "blows": [
        { "id": "S-001-B1", "dt": 0.00008, "acceleration": [/* m/s² 采样点 */] }
      ]
    }
  ]
}
```

CSV 用 `META` 行描述桩、`BLOW` 行描述锤，下一行为加速度序列。
导入解析含字段校验与逐桩错误报告，不支持 Worker 的浏览器自动降级串行分析。
