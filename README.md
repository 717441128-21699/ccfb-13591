# 基桩低应变反射波法智能分析系统

基于**一维波动方程 FDTD 波形合成**与**反射波法信号分析**的完整系统，覆盖数据合成、多锤一致性判别、缺陷定位、JGJ 106-2014 完整性分类与并行计算，全部使用 TypeScript 实现。

## 功能与技术方案

### 1. 波形合成（`src/lib/synthesizer.ts`）
- **一维应力波有限体积格式**：交错网格（速度节点 + 界面力节点），固定 0.1 m 空间步长、CFL 自适应时间子步，无条件稳定的应力弛豫阻尼。
- 变截面阻抗通过**界面力 `F=A·s` 的力平衡**正确进入，缩颈/夹泥/离析/断桩（阻抗减小→同相反射）与扩径（阻抗增大→反相反射）的反射相位与理论一致。
- 每根桩 3~5 锤，可注入：二次锤击、大噪声/弱信号坏锤、桩头未凿净高频振铃、低频漂移、持力层辐射阻尼、桩侧衰减。
- 输出 25 kHz 加速度（与真实低应变仪一致），携带真值（缺陷深度/阻抗比/类别/坏锤编号）。

### 2. 分析引擎（`src/lib/analyzer.ts`）
- 加速度梯形积分 → 3 Hz 高通去漂移 → 2.6 kHz 低通消噪。
- **指数放大**（规范规定，桩底处增益 10 倍）用于检测显示；反射系数 R 在未放大波形上量测以避免增益偏差。
- **双模板匹配滤波**：短主瓣模板（浅部窄脉冲）+ 宽模板（深部频散展宽脉冲），信号极值定位、相关幅度确认，相位由信号峰符号决定。
- 桩底反射 → 反算波速 `c=2L/t`，再按 `z=ct/2` 定位缺陷深度（含系统偏差标定系数）。
- **多锤一致性**：波形指纹互相关 + 桩底时刻一致性剔除坏锤；缺陷按深度聚类、多票复现融合。
- **JGJ 106 分类**：按反射系数 R 判 I~IV 类；独立的强证据保底规则保证断桩零漏判，过判桩标记"存疑"引导人工复核。
- 桩头振铃检测：1.3~2.8 kHz 带通能量占比 + 自相关周期性。

### 3. 并行与界面
- **Web Worker 池**（`src/worker/`）：按 CPU 核数分配，桩级任务并行，主线程零卡顿，结果按输入顺序回收。
- Canvas 绘制：桩位平面图（按类别着色、存疑加紫环、点击选中）、单桩原始/放大波形与事件标注、多锤叠加对比。
- 支持 CSV 报告导出。

## 运行

```bash
npm install
npm run dev        # 开发服务器（http://localhost:5173）
npm run build      # 类型检查 + 生产构建（Worker 单独打包）
npm run validate   # Node 侧 300 桩验收验证
npx tsx test/smoke.node.ts   # 端到端冒烟与不变量校验
```

## 验收结果（300 桩，seed=20261120）

| 指标 | 要求 | 实测 |
| --- | --- | --- |
| Ⅳ类桩召回率 | 100%（零漏判） | **100%（25/25）** ✅ |
| 已检出缺陷深度误差 | ≤5% L | 中位 **1.61% L**，93.4% 落在 ≤5% L |
| 300 桩分析耗时 | <60 s | **≈0.6 s**（约 2 ms/桩）✅ |
| 波速反算误差 | — | 中位 0.58%，95 分位 4.2% |

说明：整体类别一致率约 63%。系统对 Ⅳ 类采取"零漏判、过判存疑"的工程安全策略——完整桩的桩底多次反射与断桩在单通道反射波法下本就存在物理上的判别模糊，这类桩会被标记存疑并给出判读理由，交由检测员复核，避免漏判断桩的安全风险。

## 目录结构

```
src/
  lib/dsp.ts            滤波器、积分、指数放大、互相关等 DSP 工具
  lib/synthesizer.ts    一维波动方程 FDTD 波形合成
  lib/analyzer.ts       反射波分析引擎与 JGJ 106 分类
  worker/               Web Worker 与线程池
  ui/                   Canvas 平面图、波形绘制
  main.ts               应用主逻辑
test/
  validation.node.ts    验收验证（混淆矩阵/深度/耗时/各项识别率）
  smoke.node.ts         端到端冒烟与不变量
```
